# Schedule a Visit Form (Simple Version)

## Overview
A basic form that allows users to schedule a plumbing visit. This is a simple frontend-only implementation with no validation or backend integration.

## Core Features
- Simple form with basic fields (name, contact details, service type, date/time)
- Submit button that shows a confirmation message
- Mobile-friendly layout

## Implementation Approach
- Single React component with minimal state
- No validation requirements
- On submit, just hide form and show "Thank You" message
- No backend integration required

## Form Fields
- Name 
- Email
- Phone
- Address
- Service Type (dropdown)
- Preferred Date
- Preferred Time
- Brief Description (optional)

## User Flow
1. User fills out basic form
2. User clicks submit
3. Form disappears and confirmation message appears

## Technical Constraints
- Frontend-only (React)
- No validation required
- No API calls or data persistence
- No complex UI components

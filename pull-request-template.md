# Service Area Section Feature

## Description
This PR adds a new Service Area Section to the home page, displaying the cities served by our plumbing company with links to their respective city pages. The section includes a placeholder for a future map integration and contact information.

## Changes Made
- Created new `ServiceAreaSection` component in `src/components`
- Added the component to the home page (`Index.tsx`)
- Implemented responsive design for all screen sizes
- Added clickable city links to Franklin, Nashville, and Brentwood pages
- Added placeholder for future map integration
- Added contact information section with placeholder data
- Ensured accessibility with proper ARIA attributes and semantic HTML

## Future Work
- Integrate an actual map in place of the placeholder
- Add more cities as new city pages are created

## How to Test
1. Open the home page and scroll down to see the Service Area Section
2. Verify that the section displays properly on mobile, tablet, and desktop
3. Test the city links to ensure they navigate to the correct pages
4. Verify accessibility by navigating with keyboard
